# Asset replacement guide — SYRUP PLANETS & BLUE LEMONADE

Everything currently in this project is a **code-native placeholder**
(SVG/CSS/gradients for visuals, synthesized WAVs for audio) so the project
renders fully offline. This document lists exactly what to drop in for a
photoreal master. Nothing is downloaded automatically.

## Minimum source resolution

The 4K master composition is 2160×3840. Rendering placeholders at 4K does
NOT make them true 4K detail. For photoreal quality, supply source assets
at **≥ 2160px on the short edge** (stills ≥ 2560×4550 for full-frame use;
video plates ≥ 2160×3840 @ 60fps, 10-bit preferred).

## Audio — `public/assets/audio/`

Every WAV here is a labeled synthetic placeholder generated by
`npm run gen:audio` (deterministic, seed-locked). Replace with professional
close-mic'd recordings **using the same filenames** and the mix will pick
them up with no code change. Keep peaks ≤ -6 dBFS per file; the layered mix
targets ≈ -16 LUFS integrated / ≤ -1 dBTP.

Folders: `ambience/ syrup/ pancake/ knife/ citrus/ ice/ liquid/ glass/ transitions/`
The authoritative cue list (timing, volume, fades) is `src/audio/manifest.ts`.
